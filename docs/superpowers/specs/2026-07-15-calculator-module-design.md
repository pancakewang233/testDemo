# 函数计算器模块设计

## 目标

在现有 Vue 2 示例工程中新增一个可选模块，提供紧凑按键式函数计算器界面。用户通过按钮组装数学表达式，再将原始表达式提交给后端计算。

本期不在前端执行表达式，也不解析后端返回值的业务语义。

## 页面与交互

- 新模块名称为 `CalculatorModule`，在 `App.vue` 的模块选择器中可进入。
- 页面顶部显示当前表达式；没有表达式时显示占位提示。
- 使用紧凑按键布局：`ln`、`log`、幂运算 `xʸ`、平方根 `√`、`eˣ`、`sin`、`cos`、`tan`、`abs`、`round`、数字键、退格、清空、提交。
- 函数键插入后端可识别的文本片段：`ln(`、`log(`、`sqrt(`、`exp(`、`sin(`、`cos(`、`tan(`、`abs(`、`round(`。
- 幂运算键插入 `^`；数字键和普通括号拼入表达式；退格删除最后一个字符；清空删除全部内容。
- 点击提交前，空表达式会被拦截并提示用户输入；提交中禁用提交按钮以避免重复请求。

## 模块边界

`CalculatorModule.vue` 负责布局、按钮事件、表达式状态、请求状态和结果展示。

表达式组装和校验抽为无副作用的小函数，便于通过 Node 脚本测试，不依赖浏览器或 Vue 运行时。

`App.vue` 只负责动态加载计算器模块和在选择器中提供入口，不承载计算器业务状态。

## 后端请求约定

由于尚未提供后端接口定义，本期采用可替换的默认约定：

```text
POST /api/calculator/expressions
Content-Type: application/json
{ "expression": "ln(2)+2^3" }
```

接口地址和请求字段名称集中定义在组件顶部。后端实际约定确定后，只修改该处即可。

请求成功后，模块展示后端返回的 `result` 字段；若响应没有该字段，则以格式化 JSON 显示响应。非 2xx 响应、网络错误、无效 JSON 均显示错误提示并保留当前表达式，供用户修改后重试。

## 测试与验证

新增 Node 断言脚本，覆盖：

1. 函数键和幂运算键按约定组装表达式。
2. 退格与清空的边界行为。
3. 空白表达式不能提交。
4. 成功、失败和提交中的请求状态由组件方法处理。

实施完成后运行新增脚本和 `npm run build`。如前端启动条件允许，再启动开发服务并通过 HTTP 状态确认可访问。

## 不在范围内

- 前端 `eval` 或自行计算数学表达式。
- 历史计算记录、变量、复杂公式编辑器、键盘光标定位。
- 后端 API、鉴权或跨域配置改造。
